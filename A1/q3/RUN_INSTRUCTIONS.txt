# How to Run the Optimized Graph Indexing Pipeline

### **Step 1: Generate Feature Patterns**

For **Mutagenicity** dataset:
```bash
python3 identify.py q3_datasets/Mutagenicity/graphs.txt features_muta.txt
```

For **NCI-H23** dataset:
```bash
python3 identify.py q3_datasets/NCI-H23/graphs.txt features_nci.txt
```

**Output**: Creates feature files (patterns found through gSpan mining)

---

### **Step 2: Convert Features to Pickle Format**

```bash
# For Mutagenicity
python3 txt_to_pkl.py features_muta.txt features_muta.pkl

# For NCI-H23
python3 txt_to_pkl.py features_nci.txt features_nci.pkl
```

**Output**: Creates .pkl files needed by convert.py

---

### **Step 3: Convert Database Graphs to Feature Matrices**

For **Mutagenicity**:
```bash
python3 convert.py q3_datasets/Mutagenicity/graphs.txt features_muta.pkl db_features_muta.npy
```

For **NCI-H23**:
```bash
python3 convert.py q3_datasets/NCI-H23/graphs.txt features_nci.pkl db_features_nci.npy
```

**Output**: Creates .npy feature matrices (50 features x N graphs)

---

### **Step 4: Convert Query Graphs to Feature Matrices**

For **Mutagenicity**:
```bash
python3 convert.py test_queries_new.txt features_muta.pkl test_query_features_muta.npy
```

For **NCI-H23**:
```bash
python3 convert.py test_queries_nci.txt features_nci.pkl test_query_features_nci.npy
```

**Output**: Query feature matrices

---

### **Step 5: Generate Candidates**

For **Mutagenicity**:
```bash
python3 candidate_gen.py db_features_muta.npy test_query_features_muta.npy candidates_muta.dat
```

For **NCI-H23**:
```bash
python3 candidate_gen.py db_features_nci.npy test_query_features_nci.npy candidates_nci.dat
```

**Output**: Candidate lists (filters using monotonicity property)

---

### **Step 6: Evaluate Precision**

For **Mutagenicity**:
```bash
python3 eval.py test_truth_new.dat candidates_muta.dat
```

For **NCI-H23**:
```bash
python3 eval.py test_truth_nci.dat candidates_nci.dat
```

**Output**: Precision metrics for each query

---

### **Complete Pipeline (One-liner for each dataset)**

**Mutagenicity**:
```bash
python3 identify.py q3_datasets/Mutagenicity/graphs.txt features_muta.txt && \
python3 txt_to_pkl.py features_muta.txt features_muta.pkl && \
python3 convert.py q3_datasets/Mutagenicity/graphs.txt features_muta.pkl db_features_muta.npy && \
python3 convert.py test_queries_new.txt features_muta.pkl test_query_features_muta.npy && \
python3 candidate_gen.py db_features_muta.npy test_query_features_muta.npy candidates_muta.dat && \
python3 eval.py test_truth_new.dat candidates_muta.dat
```

**NCI-H23**:
```bash
python3 identify.py q3_datasets/NCI-H23/graphs.txt features_nci.txt && \
python3 txt_to_pkl.py features_nci.txt features_nci.pkl && \
python3 convert.py q3_datasets/NCI-H23/graphs.txt features_nci.pkl db_features_nci.npy && \
python3 convert.py test_queries_nci.txt features_nci.pkl test_query_features_nci.npy && \
python3 candidate_gen.py db_features_nci.npy test_query_features_nci.npy candidates_nci.dat && \
python3 eval.py test_truth_nci.dat candidates_nci.dat
```

---

### **Expected Results (Current Optimization)**
- Mutagenicity: ~0.305 Avg Precision
- NCI-H23: ~0.271 Avg Precision
- Zero false negatives (verified)
